Fake News Detection Using Machine Learning
Project Overview
This project explores the detection of fake and real news using Python and machine learning techniques. It uses text-based news data to build a classification model that distinguishes between genuine and misleading news articles.
Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing (NLP)
 Dataset
The project uses real and fake news datasets containing news titles and article text.
 Project Workflow
1. Load real and fake news datasets.
2. Clean and preprocess the text.
3. Combine and label the datasets.
4. Extract text features.
5. Train machine learning classification models.
6. Evaluate model performance.
 Project File
- `Fake_New_Detection.ipynb` — Main Jupyter Notebook containing the project code.
